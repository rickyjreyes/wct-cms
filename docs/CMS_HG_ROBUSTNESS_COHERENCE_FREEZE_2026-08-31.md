## Robustness fields

For every configuration and both periods, record:

- fixed-omega free-phase amplitude
- fixed-omega free-phase phase
- phase offset from `phi_pred`
- fixed-omega two-parameter delta chi-square
- phase-locked signed amplitude
- phase-locked positive-only delta chi-square
- phase-locked one-sided analytic diagnostic p
- residual RMS
- maximum absolute residual

Primary robustness questions:

1. Does the signed amplitude remain positive in both periods across the full frozen suite?
2. Does the fixed-omega phase remain clustered around `phi_pred` rather than wandering arbitrarily?
3. Does the signal survive continuum families that materially improve residual adequacy?
4. What is the minimum phase-locked delta chi-square across the frozen suite?

No configuration may be removed from the reported envelope because it weakens the result. Failures/exceptions must be retained and explained.

## H/G coherence statistic

Canonical runner:

```bash
python scripts/run_hg_coherence.py --permutations 10000
```

At fixed `omega`, each period has a fitted coefficient vector

```text
beta_i = (a_i, b_i).
```

Define:

```text
common_score
```

as the likelihood-ratio improvement for a single common `(a,b)` coefficient shared by H and G.

Define:

```text
separate_score = score_H + score_G
heterogeneity = separate_score - common_score
```

and freeze the coherence statistic as

```text
T_coh = common_score - heterogeneity
      = 2*common_score - separate_score.
```

This rewards a large common waveform and penalizes fit improvement that only appears when the two periods are allowed to use different complex coefficients.

## Coherence null

Each paired null trial independently residual-permutes H and G, then recomputes the complete common/separate fits and `T_coh` at the same frozen `omega`.

The empirical p-value is

```text
p = (1 + number[T_null >= T_observed]) / (1 + N_null).
```

Do not multiply the separate H and G analytic p-values.

## Interpretation

- Robustness failure under reasonable continuum models is evidence against treating the present ~10.5--10.6 sigma analytic diagnostics as physical significance.
- Robust phase/sign persistence under the full suite is evidence that the feature is not an artifact of one particular degree-7 continuum choice.
- A small paired-null coherence p-value is a calibrated statement about how unusual the **joint H/G waveform agreement** is under this residual-permutation null.
- Because H and G were already inspected before `T_coh` was introduced, the coherence result remains retrospective. The Run2016F signed phase-locked test is the prospective evidence layer.
